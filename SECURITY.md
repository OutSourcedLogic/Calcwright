# Security

Calcwright is a hobby fork of Windows Calculator maintained by one person, with no formal security
response process.

If you find a security problem in Calcwright, please open an [issue](../../issues) without exploit
details and ask for a private way to share them, or use GitHub's private vulnerability reporting if
it's enabled on this repository.

Problems that also affect the official Windows Calculator should be reported to Microsoft through the
[Microsoft Security Response Center](https://msrc.microsoft.com/create-report).
