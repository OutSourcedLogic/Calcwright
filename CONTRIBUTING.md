# Contributing

Calcwright is a small personal fork of [Windows Calculator](https://github.com/microsoft/calculator).
Bug reports and suggestions are welcome as [issues](../../issues). For larger changes, please open an
issue first to discuss them.

Changes that would benefit Windows Calculator itself are best contributed upstream to
`microsoft/calculator`, following its own contributing guidelines.

Please follow the existing code style (`.editorconfig` and `.clang-format`) and run the unit tests in
`src\Calculator.Tests` before submitting a pull request.
